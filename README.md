Stand alone QT sqlite database to help organize ham radio contacts.
can be searched by name or call sign.

**HamstersDB is a simple way of keeping track of your contacts.**
I don't know about you, but I have a hard time just remembering names - much less a group of meaningless letters and a number.

I wrote a stand alone database program to help me keep track of the hamsters in my area, and I decided to share it.

You can add or edit  in both form view and table view, although I find the form view is easier.
The table view is nice for browsing through records.

The search functions match on partial data, case insensitive  - so if you search names for j it will return all names with j (or J) in them.
You can search for Names or Call Signs from the menu, or F3 will also bring up a search form.
